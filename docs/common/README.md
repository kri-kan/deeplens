# Common & Shared Specifications

This directory contains cross-cutting contracts, shared design token standards, and messaging schemas shared across DeepLens Admin (Vayyari), Background Services, and Storefront (Store.Api / Store App).

## Documents Index

- [Data Contracts](contracts.md): Canonical schemas for Products, SKUs, Inventory, Orders, and Media items.
- [Design Tokens](design-tokens.md): Tamagui token taxonomy, theme scales, swatches, typography, and responsive breakpoints.
- [Event Schemas](event-schemas.md): Kafka message payloads and topic conventions.
