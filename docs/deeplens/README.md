# DeepLens Admin & Core Services Documentation

This pillar houses the technical specifications, architecture records, guides, and testing documentation for the core DeepLens Admin platform, AI reasoning engine, background ingestion workers, and Vayyari admin client.

## Documents & Directories

- **`architecture/`**: DTO standards, hybrid architecture ADRs, AI monorepo design, persistent auth, WhatsApp pipeline, MCP intelligence.
- **`guides/`**: Catalog & media workflows, mobile build and deploy, troubleshooting, UI design preview workflow, ffmpeg setup.
- **`technical/`**: Services matrix, Kafka topics, database standards, video processing, observability, SKU requirements.
- **`archive/`**: Historical migration notes, deep sync reviews, and release notes.
- **`Prompt templates/`**: LLM & VLM prompts for WhatsApp campaign generation and catalog enrichment.
- **`MEDIA_ARCHITECTURE.md`**: Master media processing pipeline, image hashing, and MinIO storage lifecycle.
- **`MANUAL_REGRESSION_TEST_SUITE.md`**: End-to-end regression test procedures.
- **`system-overview.md`**: System topology and domain overview.
