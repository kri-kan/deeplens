# Vayyari Haute Couture — Prelaunch SPA

A high-performance Single Page Application (SPA) showcasing the grand unveiling of the **Vayyari Haute Couture** online boutique.

## 🌟 Overview & Architecture

- **Framework**: React 19 + TypeScript + Vite 6
- **Assigned Dev Port**: `8085` (consecutive store port following `8081` Vayyari Mobile Expo & `8082` Vayyari Store Web)
- **Folder Location**: `src/experimental/storePrelaunch/` (symlinked from `storeprelaunch` and `src/storeprelaunch`)
- **Assets**: Local self-contained cinematic video loops (`hero.mp4`, `philosophy.mp4`), brand logos (`vayyari-logo.png`, `vf-logo.svg`), and artisanal Kolam SVG motifs.

## 🚀 Features & Enhancements

1. **Cinematic Hero**:
   - Background video loop with smooth gold vignette & scrim.
   - Dynamic floating golden stardust canvas animation.
   - Real-time countdown clock (Days, Hours, Minutes, Seconds) ticking live toward the Inaugural Showcase.
   - Web Audio API luxury synthesizer for ambient chimes and button interactions.
   - Video cinema controls (Play/Pause, Sound Toggle).

2. **The Inaugural Capsule Preview**:
   - 4 signature silhouettes: *Swarna Kanchipuram*, *Varanasi Imperial Brocade*, *Chanderi & Organza Whisper*, *Noor Velvet Ensembles*.
   - Interactive specification drawer inspecting pure mulberry silk composition, GI origin, and weave provenance.

3. **Interactive VIP Waitlist & Golden Digital Pass**:
   - Email validation with couture preference filters.
   - Generates a bespoke **VIP Founding Member Digital Passport** (`#VY-2026-XXXX`).
   - Celebratory golden confetti burst animation (`canvas-confetti`).
   - One-click copy invitation code & instant share to WhatsApp.
   - Persistent `localStorage` memory across sessions.

4. **Brand Story & Atelier Guarantees**:
   - Certified Silk Mark handloom guarantee.
   - Master artisan weaver cluster direct patronage.

5. **Verified Boutique Channels**:
   - Instagram (`@vayyari_fashions`), WhatsApp Concierge, Facebook, and YouTube craft documentaries.

## 🛠️ Quick Commands

```bash
# Start development server on port 8085
npm run dev

# Build production bundle
npm run build

# Preview production build on port 8085
npm run preview
```
