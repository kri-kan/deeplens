# Ecommerce Preview

A React Native Expo app and Storybook playground for the VAYYARI-style commerce design system.

## Structure

- `src/components` – reusable UI primitives and screens
- `src/theme/designTokens.ts` – colors, spacing, radius, shadows
- `src/**/*.stories.tsx` – Storybook stories for component previews

## Run the app

```bash
npm start
```

For Storybook in Expo, use the app entry or configure a storybook-native launcher as needed.
